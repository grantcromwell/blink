V1: For my first iteration of the project, I engineered a data bus between a Raspberry Pi 4 and a Raspberry Pi Pico. For the Raspberry Pi, I used one of my old microSD cards with Debian 12, changed the boot configuration to enable UART, and configured the USB-C port to enable serial communication instead of only power. After that, I added a serial login service and two kernel modules, gserial and dwc2. When gadget mode began working, the serial console prompted me for a password. I hadn't realized the login on the image might require one, so that was something I had to address. After some debugging, I got the serial console working without a password and began building an application to blink an LED on the Pico over UART.

V1.5: After completing the first iteration, I realized I could simplify the project by running embedded Linux on the Raspberry Pi and using an IDE with built-in MicroPython support, such as Thonny. First, I cloned Buildroot and added the packages my Raspberry Pi image needed for serial communication and file transfer. It took time to work through all the options, but eventually I was able to add the configurations I needed. After some troubleshooting with virtual serial port enumeration, I got the image to run the Python script I wanted, which communicated with a Raspberry Pi Pico to blink the LED.

V2: For my third iteration, I used two Raspberry Pi Picos. After connecting one Pico to an I2C display, I tested the display's pins with a multimeter and confirmed the screen was receiving voltage. After importing the display library, I was able to print a 0 to the display while the LED was off and a 1 while it was on.
